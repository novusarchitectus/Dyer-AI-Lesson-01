# Dyer AI Lesson 01

Вопросы коллег к встрече по ИИ в бюро Dyer. Ответы звучат вживую, на сайте только вопросы.

Как пользоваться:
- одна полная прокрутка колесом мыши — следующий вопрос (шкала справа показывает, сколько осталось);
- стрелки, Page Up/Down и пробел тоже листают, клавиша M открывает список;
- кнопка «Вопросы» слева открывает список и переносит к любому вопросу;
- на телефоне — свайп вверх и вниз.

Сайт — один файл `index.html`, без сборки. GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.
