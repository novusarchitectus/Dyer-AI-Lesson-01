## Промпты из презентации (дословно)

**Стр. 5. Очистка зала (Nano Banana Pro).** Привязка к кадру: модель работает лучше всего, когда промпт жёстко привязан к объектам, которые уже есть в сцене. Сначала пишем не «красивый интерьер», а действия с конкретными объектами в кадре: стенами, колоннами, проёмами.
> Убери все обьекты стоящие на полу. Убери пленку с окна. Убери стоящие на полу зеркала. Закрой открытые двери. Убери проводку, которая открыто находится на стене. Закатай все стены в светлую штукатурку. Закрой отверстия на полу подходящей плиткой. Убери с потолка всяческие датчики, оставь исторические молдинги и люстры. Не трогай лепнину и декоративные элементы.

**Стр. 6. Маркировка.**
> Сгенерируй из первой фотографии стильный интерьер с баром. Требования к интерьеру - не менять цвет стен, не трогать лепнину, не убирать предметы освещения. На второй фотографии есть маркировка объектов которые нужно вставить: красным цветом - барная стойка; зеленым цветом - современные барные стулья; синим цветом - за барным столом у стены находится зона с барной утварью; Фиолетовым цветом - диванная зона из современной стильной мебели темного цвета, с журнальным столиком из рифленого стекла с подсветкой внутри. Подбери современные предметы интерьера в эти блоки, не меняй размер блоков при этом, мебель должна соответствовать габаритам блоков. Сотри все цветные маркировки и оставь только интерьер. Не менять пропорции помещения и не трогать детали. Фотореалистичный рендер интерьера. Сотри все цветные маркировки предметов из с кадра*
> *Иногда важно повторяться в промпте

**Стр. 7. Смена стилистики по тексту.**
> Сделай интерьер очень современным, не трогая при этом лепнину, отделку пола, колонны. Не меняй пропорции помещения и обьектов. Можно добавлять источники света, ковры и другие предметы для достижения результата. Фотореалистичный рендер интерьера бара с зоной отдыха

**Стр. 11. Рендер по 3D-объёму и тексту (цех).**
> Сгенерируй фотореалистичную визуализацию интерьера. На основе 3д модели из первого кадра выполни интерьер старого Цеха с новой постройкой общественного характера внутри. Старайся сохранить геометрию здания. Внешние стены здания отображают старинную индустриальность, выразительные текстуры и материалы, ветхие железобетонные конструкции, стальные конструкции и конструкции из красного кирпича, и крыша из старых ферм, как будто это старый цех. Внутри этого цеха находится новая разноуровневая теплая постройка общественного и рекреационного назначения из премиальных современных материалов и ЛСТК. Внутри здания цеха, но снаружи новой постройки, ближе к камере находится зона фудкорта, так же есть зоны отдыха снаружи нового сооружения внутри старого цеха. Необходимо отобразить контраст между старинным индустриальным зданием цеха и новой конструкцией общественного внутри него. Новая конструкция выполнена из прозрачного поликарбоната, внутри новых конструкций горит свет, ходят люди, здание используется для активного отдыха, лекций, мероприятий, мосты и переходы выполнены из стальных балок и прозрачным стеклянным покрытием с ленточным освещением, из под стеклянного покрытия мостов и переходов проглядываются посетители здания. Современное освещение общественного досугового пространства внутри старого интерьера. Полностью сохрани геометрию здания и не меняй ракурс с уровня человеческого глаза. Фотореалистичная визуализация интерьера

**Стр. 19. Агенты (план блока 2).**
- Агент №1 «ГеоКонтроль»: для жёстких коммерческих рендеров по нетекстурированным 3D-моделям.
- Агент №2 «Атмосфера»: для ландшафтов, общественных пространств и баз отдыха. Работает без геометрии, переносит атмосферу с референса леса или природы.
- Агент №3 «Коммерческий ракурс»: для предметных журнальных кадров, макродеталей и акцента на материалах.
- Агента в Syntxis делаем для того, чтобы задать JSON-структуру промпта.
- Постпродакшн: апскейл в Topaz / Magnific, докрутка микродеталей, фактуры ткани и кинематографичного света. Вариант доработки через GPT Image 2.

**Итерационный цикл (стр. 2).** Коммерческая визуализация не делается за один клик. Первая генерация — это основа, которую мы планомерно дожимаем. Три способа инпейнта: текст + инпейнт в Syntx, текст + инпейнт с обводкой объекта из Photoshop, текст + коллаж.
